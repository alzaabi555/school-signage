# دليل هيكلة Google Sheets وربط Google Apps Script
## نظام الشاشات الذكية المدرسية (School Digital Signage System)

هذا المستند يشرح بالكامل هيكلة ملف Google Sheets وكيفية ربطه بـ Web App.

---

### 1. هيكل أوراق العمل (Sheets) والأعمدة المحددة

الملف يتكون من 5 أوراق عمل رئيسية بالأسماء التالية:

#### الورقة 1: `الاحتياط_اليومي`
| اسم العمود | النوع | وصف الحقل | مثال |
| :--- | :--- | :--- | :--- |
| `المعرف` | نص | كود فريد للسجل | `SUB-101` |
| `التاريخ` | تاريخ | تاريخ اليوم | `2026-09-25` |
| `الحصة` | نص | الحصة البديلة | `الحصة الثانية` |
| `الصف` | نص | الصف الدراسي | `أول ثانوي (أ)` |
| `المعلم_الغائب` | نص | اسم المعلم المتغيب | `أ. خالد الشمري` |
| `المعلم_البديل` | نص | اسم المعلم المكلف بالاحتياط | `أ. أحمد السعيد` |
| `المادة` | نص | المادة الدراسية | `رياضيات` |
| `الحالة` | نص | حالة التكليف | `مؤكد` أو `قيد الانتظار` |
| `ملاحظات` | نص | توجيهات إضافية | `حل تدريبات صفحة 45` |
| `وقت_التحديث` | نص | تاريخ ووقت الإدخال | `2026-09-25T07:15:00Z` |

| `المعاونون` | نص | قائمة المعلمين المعاونين | `أ. ماجد الحربي، أ. صالح العمري` |
| `وقت_المناوبة` | نص | التوقيت | `الصباح والانصراف` |

| `الترتيب` | رقم | الترتيب التسلسلي | `1` |

### 2. خطوات التثبيت والتهيئة التلقائية

1. أنشئ جدول بيانات جديد على Google Sheets (سمّه مثلاً: "قاعدة بيانات الشاشة المدرسية").
2. من القائمة العلوية اختر **إضافات (Extensions)** > **Apps Script**.
3. افتح الملف `Code.gs`، انسخ الكود الموجود في مجلد المشروع `gas/Code.gs` والصقه بدلاً من أي كود سابق.
4. من شريط الأدوات، اختر الدالة `setupSchoolSpreadsheet` ثم اضغط على زر **تشغيل (Run)**.
   * سيطلب Google منح الأذونات للوصول إلى جداول البيانات، اضغط "مراجعة الأذونات" ثم "السماح".
   * ستُنشئ الدالة جميع أوراق العمل الـ 5 بالأعمدة الدقيقة والألوان والبيانات التجريبية فوراً!
5. اضغط على الزر الأزرق **نشر (Deploy)** > **نشر جديد (New deployment)**.
6. اضغط على رمز الترس بجانب "Select type" واختر **تطبيق ويب (Web app)**.
7. اضبط الإعدادات:
   * **الوصف (Description)**: API الشاشة المدرسية
   * **تنفيذ كـ (Execute as)**: أنا (حسابك)
   * **من لديه حق الوصول (Who has access)**: أي شخص (Anyone)
8. اضغط **نشر (Deploy)** وانسخ الرابط المنتهي بـ `/exec`.
9. ادخل إلى لوحة تحكم التطبيق (تبويب "الربط مع Google Sheets") والصق الرابط واضغط "اختبار الاتصال".

### 3. استدعاء الـ API من التطبيق (CORS & Endpoints)

* **طلب البيانات (GET)**:
  `GET https://script.google.com/macros/s/.../exec?action=getAllData`
  يُرجع كائن JSON كامل يحتوي على:
  `{ status: "success", schoolName, substitutions, duties, periods, announcements, timetable }`

* **إرسال الاحتياط (POST)**:
  `POST https://script.google.com/macros/s/.../exec`
  مع جسم الطلب:
  ```json
  {
    "action": "add_substitution",
    "data": {
      "period": "الحصة الأولى",
      "gradeClass": "أول ثانوي (أ)",
      "absentTeacher": "أ. خالد الشمري",
      "substituteTeacher": "أ. أحمد السعيد",
      "subject": "رياضيات",
      "status": "مؤكد",
      "notes": "حل تدريبات الدرس"
    }
  }
  ```
